# 영월-문경 여행 일정

2026년 8월 29일~31일 영월-문경 여행 일정을 보기 좋게 정리한 정적 페이지입니다.

## 실행

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 배포

GitHub Pages로 배포합니다. 일정 수정은 레포에 push할 수 있는 계정에서 `app.js`를 수정한 뒤 다시 배포하면 반영됩니다.

## 구성

- `index.html`: 앱 화면
- `styles.css`: 대시보드 스타일
- `app.js`: 일정 데이터와 렌더링
